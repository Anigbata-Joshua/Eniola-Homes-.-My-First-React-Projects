Eniola Homes - Real Estate Platform

A modern, responsive real estate website built with React and Vite. Eniola Homes showcases properties, team expertise, and provides a seamless user experience for clients looking to find their dream home.

Project Overview

Eniola Homes is a full-featured real estate platform designed to connect buyers with their perfect property. The website features a beautiful hero section, comprehensive team information, property showcases, and an easy contact system.

Live Features:
- ✨ Stunning hero landing page with call-to-action buttons
- 👥 Professional team member profiles with sales achievements
- 📊 Company statistics (2B+ in sales, 500+ properties sold, 98% satisfaction)
- 📝 Contact page with inquiry form and office information
- 📱 Fully responsive design for all devices

Tech Stack

-  Framework: React 
- Routing: React Router DOM 7.13.2
- Styling: Tailwind CSS

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository or navigate to the project folder:
```bash
cd "React class - Assignment"
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173` (default Vite port)

## 📋 Available Scripts

- `npm run dev` - Start development server with hot module replacement
- `npm run build` - Build the project for production
- `npm run preview` - Preview the production build locally
- `npm run lint` - Run ESLint to check code quality
